# 统一设置窗口与模型选择

依据用户本轮明确修改要求直接实施，替代此前“选择未配置模型即打开配置、保存并切换”的交互。

- 托盘“模型设置”改为“模型选择”，打开普通设置窗口的模型列表。
- 模型每行分离选择与维护操作：未下载／未配置不能选择；同行按钮打开下载或配置页面。保存或下载完成只更新就绪状态，返回列表，由用户显式选择。
- 模型列表、DeepSeek 密钥与连接测试、模型下载、常用设置共用一个不透明、带系统标题栏的设置窗口。沿用现有深灰／红色风格，统一标题、间距、表单及操作按钮。
- 常用设置提供界面语言、录音设备和 Zipformer 模型版本；保留高级配置文件入口，避免扩展本轮未要求的全部参数编辑器。
- 同一个原生窗口分为两种互斥模式：设置模式有标题栏、任务栏入口、正常焦点和不透明背景；胶囊模式无标题栏、透明、不抢焦点。切换期间隐藏窗口，准备最终尺寸和内容，渲染完成后只显示一次。
- 配置窗口关闭仅隐藏并恢复胶囊模式，不退出进程。设置窗口位置不污染胶囊位置记忆。所有模式变更串行，录音期间不切换。
- 嵌入下载向导时禁止其自行改窗口尺寸、拖动整个窗口或退出应用；离开下载页取消未完成的下载。

验证：未就绪模型禁用但操作按钮可用；保存不切换；窗口打开时序、关闭与位置隔离；首次与重复打开、原生标题栏／焦点／透明模式切换；本地及云端回归。
