# DeepSeek 独立云端语音识别引擎

状态：用户已确认，已实施。用户已选择独立云端引擎，并要求切换前检查配置、缺失时弹出 UI、在 UI 中配置并测试有效性。以下细节为实施建议。

## 目标与方案选择

在 Nextalk 中增加可切换的 DeepSeek 云端识别引擎，沿用现有快捷键录音、处理状态、文本后处理及 Fcitx5／GNOME／剪贴板提交链路。

已选择独立云端引擎：录音结束后上传并获取完整文本，无需加载本地识别模型。另一方案是本地预览加云端重识别，能够提前显示文字，但需要同时运行两套识别流程、协调结果替换，本次不采用。

## 官方接口约束

来源：https://api-docs.deepseek.com/zh-cn/guides/asr/ （2026-11-13 查阅）。

- POST `https://api.deepseek.com/v1/tools/asr`，Bearer API Key。
- multipart/form-data 的 `file` 字段上传音频，读取 JSON 中的 `text`。
- 支持 16 位 PCM WAV 和 Ogg Opus；单请求最多 120 秒、8 MiB；不支持流式识别，语种自动检测。
- 使用现有 16 kHz 单声道采集，转换为 PCM16 WAV；无需模型参数或语言参数。

## 用户行为与配置

- 托盘引擎菜单增加“DeepSeek（云端）”，保留当前默认引擎。
- 新增 DeepSeek 配置窗口，支持在 UI 中输入、测试和保存 API Key，保存后立即生效，无需编辑文件或重启。沿用 settings.yaml 持久化，增加 `model.deepseek` 配置及说明。密钥默认遮罩显示，可手动切换可见性，不写入日志或诊断错误，不要求用户在聊天中提供。
- 密钥来源优先级为 UI／配置文件中保存的非空 `api_key`，其次为 `DEEPSEEK_API_KEY`；窗口标明当前来源，确保 UI 保存的新密钥实际生效，不被环境变量悄悄覆盖。
- 云端模式开始前校验密钥配置，跳过本地模型下载、验证及静音预热。
- 录音期间显示录音状态，停止后显示处理中，成功后提交全文；没有实时文字预览。
- 第一版建议单次录音达到 120 秒时自动结束并识别，界面说明时长上限。暂不实现跨请求长录音拼接，以避免切断词语和增加失败恢复复杂度。若需要无限长录音，应在实施前改为分段方案。
- 云端请求失败时显示可理解的错误，不提交部分文本，不自动切换到其他识别引擎，不自动重试付费请求。

## 配置窗口与切换流程

现有托盘“设置”仅打开配置目录，没有可复用的密钥编辑界面，因此新增应用内配置视图，并复用现有窗口服务展示。

1. 点击“DeepSeek（云端）”后检查有效配置来源；无非空密钥时先打开配置窗口，保持原引擎运行，不提前持久化引擎选择。
2. 窗口提供 API Key 输入框、显示／隐藏按钮、测试连接按钮、保存并切换按钮和取消按钮，并说明音频会上传到 DeepSeek。
3. 用户编辑的是草稿；“测试连接”直接测试当前草稿，无需先保存。输入为空时禁用测试和保存。请求中显示进度并避免重复点击。
4. 测试通过实际 ASR 接口上传程序生成的 1 秒静音 PCM16 WAV，验证鉴权、接口可达性和响应结构；HTTP 200 且合法文本字段（允许空文本）表示连接有效。该测试不代表真实语音识别准确率，界面注明会产生约 1 秒音频的 API 用量，不采集麦克风音频。
5. 显示测试成功，或区分密钥无效、余额／权限不足（依据实际响应）、限流、网络错误、服务错误和超时；错误信息脱敏。修改密钥后清除旧测试结论，迟到的响应不得覆盖新草稿状态。
6. 测试为用户主动操作，不强制每次切换联网测试；非空配置可保存并切换。保存失败则保留窗口、草稿和原引擎；只有配置保存及引擎初始化成功后才更新当前引擎。取消不保存、不切换。
7. 已配置时直接切换；另提供常驻“DeepSeek 配置…”入口，便于修改密钥和重新测试。配置缺失的启动场景也进入同一配置流程，不触发本地模型下载。
8. 关闭窗口取消未完成测试；录音或提交期间不强行切换引擎，提示结束当前操作后重试。配置窗口显示时避免录音胶囊的自动隐藏／缩放干扰编辑。

持久化沿用项目配置文件方式，采用原子更新并保留其他配置，保存含密钥的文件时限制为当前用户读写；不将密钥复制到 SharedPreferences。测试请求使用快照密钥，未保存的草稿不得影响正在使用的引擎。

## 实现边界

- 新增 DeepSeek 引擎及独立 HTTP 客户端，复用现有 dio 依赖；录音数据只在本次会话内存中保存。
- 将识别收尾接口调整为可等待异步结果，并更新所有调用处；本地引擎保持同步执行能力。
- 停止时先排空尾音、关闭麦克风，再等待网络请求，避免网络延迟延长麦克风占用。
- 取消录音必须直接丢弃缓冲区，不能复用会触发上传的收尾操作；取消请求使用取消令牌。
- 通过会话标识隔离请求和结果；取消、重新录音、切换引擎或退出后，旧请求不得提交文字、清空新缓冲区或覆盖新会话状态。
- 配置明确的连接和响应超时；分别处理鉴权失败、限流、服务不可用、超时和响应格式错误。空文本作为无识别结果处理。
- 云端模式不依赖本地 VAD；通过手动停止或时长上限结束录音。错误后允许重新录音。

## 验证与完成条件

- 用本地模拟 HTTP 服务／客户端验证 multipart、Bearer、WAV 头和 PCM 编码、成功与空响应、异常与超时、取消及旧会话结果隔离。
- 验证密钥优先级、引擎配置与切换、无本地模型启动、120 秒边界、取消录音不上传。
- 验证未配置切换弹窗、草稿测试、编辑后测试失效、取消不保存、保存立即生效、保存失败保留原引擎、已有配置直接切换和配置入口可重新打开。
- 运行相关 Flutter 测试和静态分析，回归本地引擎收尾及文字提交行为。
- 真实 API 验证需要本机已配置有效密钥；未完成真实调用时必须明确说明，不将模拟验证表述为线上验证。
- 更新中文使用文档及必要的中英文界面文案，说明云端上传、密钥配置和录音时长限制。
