# 版本提示与自动升级

用户已选择“按建议直接实现”，跳过设计问答。

- 沿用 GitHub Releases 的正式版本和现有 DEB/RPM 包。启动 20 秒后后台检查，持久化检查时间，每 24 小时最多自动请求一次；支持关闭自动检查和手动检查。开发构建不升级。
- 新版本通过系统通知、托盘和设置页提示；通知延后到录音/识别空闲时，不主动打开窗口。
- 用户在设置页点击“立即升级”并确认后，自动下载匹配版本与架构的包，检查大小和 SHA-256，再调用 pkexec 和系统包管理器安装。Linux x86_64 的 Debian/Ubuntu 使用 apt-get，Fedora/RHEL 系使用 dnf；其他平台或缺少摘要时给出手动下载入口。
- 摘要取自固定 GitHub 仓库 REST API 的 release asset digest。拒绝预发布、降级、非本仓库下载 URL 和不匹配包名。不执行远端脚本。
- 下载可取消；安装过程中锁定设置窗口关闭、模型切换和托盘退出，并阻止录音。认证取消、网络错误、校验失败和安装失败均可重试，临时文件清理。系统安装成功后提示退出并重新打开应用，不宣称旧进程已运行新版本。
- 方案取舍：选用现有系统包管理器以一起升级应用和 Fcitx5 插件；仅跳转浏览器无法完成自动安装；自行覆盖 /opt 文件会绕过包管理数据库，因此不采用。

参考：[GitHub release assets API](https://docs.github.com/en/rest/releases/assets)。
