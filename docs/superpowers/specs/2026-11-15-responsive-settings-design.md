# 设置窗口自适应

用户要求直接增加大小自适应，延续本会话直接实施的偏好。

原行为：打开设置时每次强制设为 720×680，原生窗口允许缩放，但最小尺寸为 560×560。

实施：

- 沿用当前主屏居中策略，从主屏工作区的逻辑像素尺寸计算默认大小，预留标题栏和屏幕边缘空间，不重复应用 DPI 缩放。
- 默认尺寸上限 960×820；用户可继续手动放大。通常最小尺寸为 420×360，工作区更小时最小尺寸也降低。获取屏幕信息失败时以保守尺寸降级。
- 设置窗口普通尺寸在关闭或退出时保存；再次打开恢复并按当前工作区收缩。最大化/最小化尺寸不覆盖普通尺寸；独立存储键，不污染胶囊位置。
- 标题栏导航允许换行；表单下拉框和模型维护按钮在窄窗口或大字体时改为上下排列。宽窗口限制正文最大宽度，短窗口允许外壳滚动，正文保留独立滚动。
- 缩放不重新创建配置页面，保留未保存的输入和下载/升级状态。

验证范围：工作区与脏尺寸纯函数测试、原生通道尺寸保存/恢复测试、320×280 / 420×360 / 1200×900 的 1.8 倍字体界面测试、配置草稿保留测试，以及全量回归和 Linux 构建。物理多屏/桌面缩放仍需实机验收。

验证结果：`flutter test --no-pub` 共 903 项通过、6 项跳过；本次新增 13 项测试。Linux Release 构建成功，`git diff --check` 通过。定向静态分析只报告 `window_service.dart` 原有的 `unnecessary_getters_setters` 提示，无新增问题。
